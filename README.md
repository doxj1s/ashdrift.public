# ASHDRIFT.org

Static public landing page for ASHDRIFT.org.

No application code, credentials, private notes, deployment secrets, or user data belong in this repository.

## Structure

- `index.html` — landing page
- `assets/css/` — site styles, if/when CSS is split from the page
- `assets/images/` — logos, icons, screenshots, and other local image assets

## Development

The site is intentionally simple and static. Open `index.html` directly in a browser or serve the repository root with any basic local HTTP server.

Avoid adding frameworks, trackers, externally hosted fonts, analytics, or other third-party dependencies without a concrete requirement and privacy review.

## Project status

ASHDRIFT is under active development. This repository is for the public website only; application code belongs in the main ASHDRIFT repository.
